3Q: Explain Polymorphism in C# using inheritance and interfaces with an example.
A: Polymorphism:
    -> Polymorphism came from Greek words: POLY means many, and MORPH means forms.
    -> It simply means many forms.
    -> There are 2 types of polymorphism: 
            
            i. Compile Time Polymorphism
              Ex: Method Overloading
                -> Multiple methods with the same name but with different parameters (number of parameters OR type of parameters OR order of parameters)
                -> The method will gets called based on the parameters that we pass.
                -> The method which will be called is decided at the compile time only.

            ii. Run Time Polymorphism
              Ex: Method Overriding
                -> Multiple methods with the same name and same parameters with inheritance.
                -> The overridden method will gets called in runtime.
    -> Ex:

          class Animal{
            private string sound;
            
            public Animal(string sound){
              this.sound = sound;
            }

            public string getSound(){
              return this.sound;
            }

            public string getFood(){
              return "Non-veg";
            }

            public string getFood(string food){
              return food;
            }

          }

          class Cat: Animal {
            private string food;

            public Cat(string sound, string food):base(sound){
              this.food = food;
            }

            public void getFood(){
              return this.food;
            }
          }

          class Dog: Animal {
            private string food;

            public Cat(string sound, string food):base(sound){
              this.food = food;
            }

            public void getFood(){
              return this.food;
            }
          }

          public Program(){
            Animal cat = new Cat("Mew", "Fish");
            Animal dog = new Dog("Woof", "Bone");

            Console.WriteLine($"Cat says: {cat.getSound()}...");
            Console.WriteLine($"Cat eats: {cat.getFood()}...");
            Console.WriteLine($"Dog says: {dog.getSound()}...");
            Console.WriteLine($"Dog eats: {dog.getFood()}...");
          }

7Q: What are the differences between INNER JOIN, LEFT JOIN and RIGHT JOIN in SQL?
A: INNER JOIN:
      -> It will join 2 or more tables and gives the matching values
   RIGHT JOIN:
      -> It is used to join two tables and gives the all values from the RIGHT table irrespective of the matching. It is also known as RIGHT OUTER JOIN.
  LEFT JOIN:
      -> It is also known as the LEFT OUTER JOIN. It is used to get the all values from the LEFT table irrespective of the condition.

8Q: What is the purpose of an index in SQL, and how do index improve query performance? What are some downsides of using them?
A: INDEX is used to make the queries fetch the data faster. By adding an index to an column value which is frequently queried, the SQL can easily find the data using the index. But using too many indexes, the SQL querying may get slower.
